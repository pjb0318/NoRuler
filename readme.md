# NoRuler

> **I don't want to find a ruler.**

제품 치수를 익숙한 물건과 같은 비율의 3D 공간에서 비교하는 MVP입니다.

## 실행

Node.js 22.18 이상이 필요합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소로 접속합니다. 별도 API 키나 서버, 데이터베이스는 필요하지 않습니다.

```sh
npm run build       # 타입 검사 및 프로덕션 빌드 → dist/
npm run preview     # 빌드 결과 미리보기
npm test            # 치수 변환, 입력 검증, 모델 실측, 배치 테스트
npx playwright install chromium --only-shell
npm run test:e2e    # 데스크톱·모바일 사용자 흐름 검증
```

## MVP 기능

- 제품명 및 가로(Width) / 깊이(Depth) / 높이(Height) 입력
- mm / cm 전환 시 입력한 물리적 크기 유지
- 입력 치수에 따른 3D Box 생성, 모든 물건에 동일한 World Scale 적용
- A4 용지, 500mL 물병, 스마트폰, 노트북, 키보드, 27인치 모니터 동시 비교
- 상자를 마우스·손가락으로 드래그해 바닥 위에서 이동, 위치만 초기화
- 빈 공간 드래그 회전, 휠·핀치 확대/축소, 우클릭·두 손가락 드래그 화면 이동
- 3D / 정면 / 위에서 보기, 전체 맞춤, 치수·격자 표시 전환
- 입력 검증, 초기화, 선택 물건 제거, 모바일 대응
- 마지막 반영 제품과 선택 프리셋을 브라우저 localStorage에 저장

## 치수와 World Scale

내부 데이터는 **mm** 단위입니다. `WORLD_SCALE = 0.01`로, **1 world unit = 100 mm**를 모든 모델에 동일하게 적용합니다. Three.js 좌표는 X=가로, Y=높이, Z=깊이입니다. 각 모델을 개별적으로 정규화하거나 보기 좋게 확대하지 않습니다. 10 cm 격자와 바닥을 공유하며, 전체 맞춤은 카메라만 조정합니다.

직교 카메라를 사용하므로 원근에 따른 객체 간 크기 왜곡 없이 비교할 수 있습니다. 화면상의 크기가 실물과 1:1이라는 뜻은 아닙니다.

입력 가능한 각 치수는 0.1–10,000 mm입니다. 입력은 버튼을 눌렀을 때 반영되며, 잘못된 입력은 기존 3D 모델을 변경하지 않습니다.

상자는 X/Z 바닥 평면 위에서 이동하며 높이와 크기는 유지됩니다. 정면처럼 바닥이 거의 보이지 않는 시점에서는 좌우로 이동합니다. 이름·치수·단위·프리셋·표시 옵션을 바꿔도 옮긴 상자의 위치는 유지됩니다. 전체 맞춤은 현재 배치를 화면에 맞추며, **위치 초기화**는 치수를 유지하고 상자만 기본 위치로 되돌립니다. 수동 배치는 현재 화면 세션에 유지되고, 페이지를 새로 열면 기본 배치로 시작합니다.

| 프리셋 | 가로 × 깊이 × 높이 (mm) | 기준 |
| --- | --- | --- |
| A4 용지 | 210 × 297 × 0.1 | 바닥에 놓인 A4, 두께는 가정값 |
| 500mL 물병 | 65 × 65 × 210 | 일반적인 원형 물병의 예시 외형 |
| 스마트폰 | 72 × 8 × 147 | 세워 놓은 6.1형 예시 |
| 노트북 | 304 × 215 × 16 | 덮개를 닫은 13형 예시 |
| 키보드 | 360 × 140 × 30 | 텐키리스 예시 |
| 27인치 모니터 | 615 × 200 × 455 | 스탠드를 포함한 예시 외형 |

프리셋은 특정 제조사의 제품 규격을 보증하지 않는 대표 치수입니다. 용량이나 화면 대각선만으로 외형 치수가 정해지지 않으므로, 실제 제품과 차이가 있을 수 있습니다. 모델은 크기 비교를 위한 단순화된 형태입니다.

## 구조

- `src/domain.ts`: 치수, 단위 변환, 검증, 프리셋, 배치, 저장 데이터 검증
- `src/scene.ts`: Three.js 모델, 공통 축척, 카메라, 격자, 치수 표시
- `src/SceneViewer.tsx`: 3D 렌더러 수명 관리 및 조작 UI
- `src/App.tsx`: 제품 입력, 프리셋 선택, 비교 목록
- `src/domain.test.ts`: 단위와 실제 모델 경계 치수 검증
- `tests/comparison.spec.ts`: 브라우저 사용자 흐름 검증

React + TypeScript + Vite + Three.js. WebGL 2를 지원하는 브라우저가 필요합니다. 폰트는 Google Fonts를 사용하며, 네트워크가 없으면 시스템 글꼴로 표시합니다.

3D 조작과 렌더링은 [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)와 [WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)를 사용합니다.
